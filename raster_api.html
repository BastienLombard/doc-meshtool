Raster

class meshtool.Raster

Regular 2D raster grid with spatial reference information (a CRS).

The raster stores a regularly spaced grid of values, such as bathymetry of elevation data.

The internal vertical convention is always z upwards. Th z_direction argument specifies the vertical convention of the input data, and is used to convert to the internal one.

Raster coordinates refer to pixel centers. Pixel data[0, 0] corresponds to the south-west corner of the raster.

Build a raster with from_file() or from_arrays().

Building

classmethod Raster.from_file(file, z_direction='up', bounds=None, crs_bounds=None, pixel_margin=10)

Construct a raster from a georeferenced raster file.

Parameters:

  • file (str or pathlib.Path) – Path to the raster file.

  • z_direction ({'up', 'down'}, default='up') – Vertical convention of the input values. Values are converted to the internal z-up convention.

  • bounds (tuple of float, optional) – Spatial extent (xmin, xmax, ymin, ymax) used to restrict the portion of the raster to read.

  • crs_bounds (pyproj.CRS or str, optional) – CRS in which bounds are expressed. If None, the raster CRS is used.

  • pixel_margin (int, default=10) – Number of additional pixels retained around the requested bounds.

Return type:

Raster

classmethod Raster.from_arrays(x, y, data, crs=None, z_direction='up')

Construct a raster from coordinates and data arrays.

The coordinate arrays must define a regularly spaced, strictly increasing grid. Data values are converted to the internal z-up convention.

Parameters:

  • x ((nx,) array_like) – Pixel-center coordinates along the x axis.

  • y ((ny,) array_like) – Pixel-center coordinates along the y axis.

  • data ((ny, nx) array_like) – Raster values.

  • crs (pyproj.CRS, str or None, default=None) – Coordinate reference system.

  • z_direction ({'up', 'down'}, default='up') – Vertical convention of the input values. Values are converted to the internal z-up convention.

Return type:

Raster.eval(x, y, point_crs=None, fill_value=nan, fill_type='closest')

Evaluate the raster at the specified coordinates using bilinear interpolation.

Parameters:

  • x (array_like) – Coordinates of the evaluation points.

  • y (array_like) – Coordinates of the evaluation points.

  • point_crs (pyproj.CRS or str, optional) – CRS of the input coordinates. If None, coordinates are assumed to be expressed in the raster CRS.

  • fill_value (float, default=np.nan) – Value returned for points outside the raster extent or where interpolation cannot be performed.

  • fill_type ({'value', 'closest'}, default='closest') – Strategy used when interpolation is not possible: - ‘value’: use fill_value. - ‘closest’: use the value of the closest valid raster pixel.

Returns:

values – Interpolated raster values at the requested coordinates.
